# Recursion Basics

Write two **recursive** functions:

* `fib(n)` - the n-th Fibonacci number, with `fib(0) = 0` and `fib(1) = 1`.
* `sum_digits(n)` - the sum of the digits of `n >= 0`, e.g. `sum_digits(123) = 6`. No loops.

Before you code: write down, in words, the smallest input of each problem and the answer to it.
