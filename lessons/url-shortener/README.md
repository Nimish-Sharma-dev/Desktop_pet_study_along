# Design a URL shortener

Design a service like bit.ly: users submit a long URL and get a short link; visiting the short link redirects to the original.

Deliverables (copy `starter/` into your workspace):

* `design.md` - one section each for **requirements, estimation, data model, API, scaling, bottlenecks, failure handling, trade-offs**.
* a diagram (`diagram.mmd` in Mermaid, or an image linked from `design.md`).

Each section is scored 0-5 against `rubric.yaml`. The pet will ask questions about the sections that are thin; it will not write them for you.
