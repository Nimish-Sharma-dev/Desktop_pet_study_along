# Socratic Tutor Pet (VS Code extension)
See the top-level README. `npm install && npm run compile`, then F5 in VS Code.
Commands: **Tutor: Run Tests**, **Tutor: Pause / Resume**, **Tutor: Reply to the Pet**.
Settings: `tutor.daemonUrl`, `tutor.allowlistedFolders`, `tutor.studentId`, `tutor.pauseOnStart`, `tutor.editCoalesceMs`.
