# Linked List Reversal

Reverse a singly linked list in place and return the new head. The `ListNode` class is already in the starter file; keep it.

```
1 -> 2 -> 3 -> 4 -> 5   becomes   5 -> 4 -> 3 -> 2 -> 1
```

Edge cases the hidden tests care about: an empty list, one node, and a very long list.
