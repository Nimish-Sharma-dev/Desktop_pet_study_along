# Design a rate limiter

Design a distributed rate limiter that protects an API: each client may make at most N requests per time window; extra requests are rejected.

Deliverables (copy `starter/` into your workspace):

* `design.md` - one section each for **requirements, estimation, data model, API, scaling, bottlenecks, failure handling, trade-offs**.
* a diagram (`diagram.mmd` in Mermaid, or an image linked from `design.md`).

Each section is scored 0-5 against `rubric.yaml`.
